# TRPG 픽셀 아이콘 팩 (32×32)

BOOTH 출품용 TRPG 소재 아이콘을 **코드로 그려서** 생산하는 프로젝트.
아이콘은 PNG를 직접 만들지 않고 `icons/<category>/<id>.py`의 그리기 코드로 정의하며,
빌드 도구가 팔레트·명암·외곽선·규격을 강제해 작업자가 달라도 같은 품질이 나오게 한다.

## 제작 방식 (v4: 시트 생성 + 규격 변환)

모든 아이콘은 **32×32 캔버스** 하나에 들어간다. 이 규격은 사람이 매번 지시하지 않아도 도구가 보장한다.

1. **목록** — `catalog/<category>.csv`에 아이콘 한 줄(id, 한/일/영 이름, `prompt_en` 묘사)을 쓴다.
2. **프롬프트** — `python tools/prompt.py <category>`가 시트별 프롬프트를 만든다. 화풍·배경색·격자 배치는 이 도구에 고정.
3. **생성** — 이미지 생성 AI(Figma 이미지 생성, `gpt-image-2.5-flare`, 1장 2크레딧)로 시트를 받아 `source/<category>/sheets/`에 저장.
4. **변환** — `tools/convert.py --sheet ...`(명령은 prompt.py가 함께 출력)가 칸별로 잘라 픽셀 격자 추정 → 배경 제거 →
   30×30 초과 시 축소 → 60색 마스터 팔레트 양자화 → 잡색·가시 픽셀 정리 → 외곽선 색 통일 → 32×32 중앙 정렬 → `pixels/<category>/<id>.png`
5. **검사·납품** — `tools/build.py`가 규격(32×32, 여백 1px, 긴 변 20px 이상, 중심, 팔레트, 가시 픽셀)을 검사하고 PNG·SVG·시트를 만든다. 위반 아이콘은 납품물에서 제외.

실측으로 얻은 운영 규칙:
- **시트 격자**: 기본 4×4(16개/장, 아이콘당 0.13크레딧). 가구처럼 형태가 큰 물체는 24~30px로 잘 나온다.
  음식처럼 작고 둥근 물체는 4×4에서 17~20px로 작게 나와 **3×3(9개/장)** 을 쓴다 (20~26px). `prompt.py`의 `GRID`에서 카테고리별 지정.
- 프롬프트의 "N pixels" 숫자를 올려도 크기는 커지지 않는다 (28→34 시험, 변화 없음). 크기는 격자 칸 수로 조절한다.
- 프롬프트 **첫 문장에 배경색**을 써야 지켜진다 (뒤에 쓰면 흰 배경으로 나온 적 있음).
- 2×2 시트·단일 생성은 원본 격자가 40칸 이상으로 나와 축소 시 뭉개지는 경우가 많다 → 쓰지 않는다.
- 크레딧 예산: 무료 한도 하루 150 / 월 500. **하루 100, 월 400 이하로 운영, 유료 결제 금지.**
- 회전(스프라이트 스태킹)은 32×32 규격과 맞지 않아 제외 (`experiments/sprite_stack/`에 시험 기록만 보관).

현황: 음식 32종, 가구 32종 완료. `archive/food_v3_single/`은 단일 생성 시절의 음식 24종(참고용),
`icons/*.py`는 코드로 그린 초기 버전(같은 id가 `pixels/`에 없을 때만 쓰이는 대체 경로).

## 사용법

```
pip install pillow numpy
python tools/prompt.py food        # 시트 프롬프트 + 변환 명령 출력
python tools/build.py food/apple   # 1개 검사 + build/preview/food/apple.png
python tools/build.py food         # 카테고리 빌드 → dist/food/
python tools/build.py --all
```

현재 `dist/<category>/` 산출물 (샘플 단계):
- `32px/`, `64px/`, `128px/` — 개별 PNG (투명 배경, 정수배 확대)
- `<category>_sheet_32px.png` — 32px 격자 스프라이트 시트 (8열)
- `<category>_preview.png` — 어두운/밝은 배경 대조 시트 (검수·상품 이미지용)

### 최종 납품 규격 (확정, 출품 빌드 때 적용 예정)

- 개별 PNG: **1배(32px), 2배(64px), 5배(160px), 10배(320px)** — 모두 정수배 최근접 확대, 투명 배경
- 개별 **SVG**: 32×32 격자를 그대로 유지 (`viewBox="0 0 32 32"`, 픽셀 = 1단위 사각형, `crispEdges`) — 이미 `dist/<category>/svg/`로 출력됨
- **전체 스프라이트 시트**: 모든 카테고리의 아이콘을 한 장에 정렬
- **개별 스프라이트 시트**: 카테고리별 시트를 따로 제공
- 미정: 시트도 4개 배율로 낼지, "개별 시트"가 카테고리 단위인지 — 출품 빌드 전에 확인

## 구조

```
catalog/   카테고리별 아이콘 목록 (id, 한/일/영 이름, 한 줄 지시)
source/    생성 AI 원본 (1024px, 단색 배경)
pixels/    변환된 확정 32px 아이콘 (빌드 입력)
icons/     코드로 그린 아이콘 (.py, 대체 경로)
tools/     convert.py (원본→32px 변환), pixelkit.py (팔레트·lint·코드 드로잉), build.py (빌드 CLI)
docs/      STYLE_GUIDE.md (작업 지침서)
dist/      납품물 (빌드 결과, 커밋됨)
```

## 로드맵

| 단계 | 카테고리 | 예시 | 수량 |
|---|---|---|---|
| 1 (샘플) | 음식 `food` | 과일, 빵, 고기, 음료, 디저트 | 24 |
| 2 | 생활 `daily` | 열쇠, 랜턴, 양초, 편지, 책, 지도, 가방, 동전 | 24 |
| 3 | 꽃·식물 `flower` | 장미, 백합, 해바라기, 약초, 화분, 꽃다발 | 24 |
| 4 | 가구 `furniture` | 의자, 탁자, 침대, 책장, 보물상자, 문 | 24 |
| 5 | 모험 도구 `tool` | 밧줄, 곡괭이, 망원경, 나침반, 물약, 두루마리 | 24 |
| 6 | 무기·방어구 `gear` | 검, 활, 지팡이, 방패, 투구 | 24 |

새 카테고리 추가 절차: `catalog/<name>.csv` 작성 → 기준 아이콘 1~2개를 상위 모델이 제작 →
나머지를 5~6개 묶음으로 하위 모델에 배정 → `python tools/build.py <name>` → 대조 시트 검수.

## BOOTH 출품 메모

- 구성안: 카테고리별 단품(24종) + 전체 합본. 각 zip에 32/64/128px PNG, 스프라이트 시트, 이용 약관(일/영) 동봉.
- 상품명·태그는 일본어 우선 (`TRPG`, `ココフォリア`, `ドット絵`, `アイコン素材`). 이름은 `catalog/*.csv`의 `name_ja` 사용.
- 출품 전 사람이 정할 것: 가격, 이용 약관(상업 이용·가공·재배포 범위), **AI 활용 제작 사실의 표기** (BOOTH의 AI 생성물 관련 가이드라인을 출품 시점에 확인).

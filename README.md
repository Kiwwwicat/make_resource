# TRPG 픽셀 아이콘 팩 (32×32)

BOOTH 출품용 TRPG 소재 아이콘을 **코드로 그려서** 생산하는 프로젝트.
아이콘은 PNG를 직접 만들지 않고 `icons/<category>/<id>.py`의 그리기 코드로 정의하며,
빌드 도구가 팔레트·명암·외곽선·규격을 강제해 작업자가 달라도 같은 품질이 나오게 한다.

## 왜 이 방식인가

| 문제 | 해결 |
|---|---|
| 이미지 생성 AI는 32px 격자·팔레트·투명도를 정확히 지키지 못하고 장마다 화풍이 흔들림 | 픽셀을 코드로 지정 → 결과가 결정적이고 재현 가능 |
| 작업자(모델)마다 색·외곽선·광원이 다름 | 60색 마스터 팔레트, 자동 명암(좌상단 광원), 자동 외곽선을 도구가 처리 |
| 크기·여백·중심이 들쭉날쭉 | `lint`가 여백/크기/중심/색 수를 검사, ERROR면 납품물에서 제외 |
| "그려놓고 안 봄" | 작업자는 매 반복마다 미리보기 PNG를 직접 보고 체크리스트로 자가 점검 |
| 나중에 팔레트·외곽선을 바꾸고 싶음 | 소스가 코드라 전체 재빌드 한 번으로 일괄 반영 |

## 역할 분담 (상위 모델 계획 → 하위 모델 실행)

1. **상위 모델 (기획·감수)**: 카테고리와 `catalog/<category>.csv` 작성, 도구·스타일 가이드 유지, 기준 아이콘 제작, 대조 시트 검수 후 반려/수정 지시.
2. **하위 모델 (제작)**: 5~6개 묶음을 병렬로 배정받아 `docs/STYLE_GUIDE.md`의 작업 루프(작성 → 빌드 → 미리보기 확인 → 수정)를 아이콘당 2~6회 반복.
3. **게이트**: ① lint ERROR 0 → ② 작업자 자가 점검 → ③ 상위 모델의 대조 시트 검수 → ④ 사람의 최종 확인.

## 사용법

```
pip install pillow
python tools/build.py food/apple   # 1개 검사 + build/preview/food/apple.png
python tools/build.py food         # 카테고리 빌드 → dist/food/
python tools/build.py --all
```

현재 `dist/<category>/` 산출물 (샘플 단계):
- `32px/`, `64px/`, `128px/` — 개별 PNG (투명 배경, 정수배 확대)
- `<category>_sheet_32px.png` — 32px 격자 스프라이트 시트 (8열)
- `<category>_preview.png` — 어두운/밝은 배경 대조 시트 (검수·상품 이미지용)

### 최종 납품 규격 (확정, 출품 빌드 때 적용 예정)

- 개별 PNG: **1배(32px), 2배(64px), 5배(160px), 10배(320px)** — 모두 정수배 최근접 확대, 투명 배경
- **전체 스프라이트 시트**: 모든 카테고리의 아이콘을 한 장에 정렬
- **개별 스프라이트 시트**: 카테고리별 시트를 따로 제공
- 미정: 시트도 4개 배율로 낼지, "개별 시트"가 카테고리 단위인지 — 출품 빌드 전에 확인

## 구조

```
catalog/   카테고리별 아이콘 목록 (id, 한/일/영 이름, 한 줄 지시)
icons/     아이콘 소스 (.py)
tools/     pixelkit.py (팔레트·도형·명암·외곽선·lint), build.py (빌드 CLI)
docs/      STYLE_GUIDE.md (작업 지침서)
dist/      납품물 (빌드 결과, 커밋됨)
```

## 로드맵

| 단계 | 카테고리 | 예시 | 수량 |
|---|---|---|---|
| 1 (샘플) | 음식 `food` | 과일, 빵, 고기, 음료, 디저트 | 24 |
| 2 | 생활 `daily` | 열쇠, 랜턴, 양초, 편지, 책, 지도, 가방, 동전 | 24 |
| 3 | 꽃·식물 `flower` | 장미, 백합, 해바라기, 약초, 화분, 꽃다발 | 24 |
| 4 | 가구 `furniture` | 의자, 탁자, 침대, 책장, 보물상자, 문 | 24 |
| 5 | 모험 도구 `tool` | 밧줄, 곡괭이, 망원경, 나침반, 물약, 두루마리 | 24 |
| 6 | 무기·방어구 `gear` | 검, 활, 지팡이, 방패, 투구 | 24 |
| 7 | 보석·재료 `material` | 보석, 광석, 가죽, 깃털, 약초 재료 | 24 |

새 카테고리 추가 절차: `catalog/<name>.csv` 작성 → 기준 아이콘 1~2개를 상위 모델이 제작 →
나머지를 5~6개 묶음으로 하위 모델에 배정 → `python tools/build.py <name>` → 대조 시트 검수.

## BOOTH 출품 메모

- 구성안: 카테고리별 단품(24종) + 전체 합본. 각 zip에 32/64/128px PNG, 스프라이트 시트, 이용 약관(일/영) 동봉.
- 상품명·태그는 일본어 우선 (`TRPG`, `ココフォリア`, `ドット絵`, `アイコン素材`). 이름은 `catalog/*.csv`의 `name_ja` 사용.
- 출품 전 사람이 정할 것: 가격, 이용 약관(상업 이용·가공·재배포 범위), **AI 활용 제작 사실의 표기** (BOOTH의 AI 생성물 관련 가이드라인을 출품 시점에 확인).

# 스타일 가이드 / 작업 지침서

아이콘 1개 = `icons/<category>/<id>.py` 파일 1개. `def draw(c):` 하나만 정의한다.
모든 작업자(사람·AI)는 이 문서와 기준 아이콘 2개만 보고 같은 품질을 내야 한다.

- 기준 아이콘(둥근 물체): `icons/food/apple.py` — 자동 명암 + 수동 하이라이트
- 기준 아이콘(각진 물체): `icons/food/cheese.py` — 면 단위 고정색

## 1. 고정 규칙 (도구가 강제)

| 항목 | 규칙 |
|---|---|
| 캔버스 | 32×32, 투명 배경, 알파는 0 또는 255만 |
| 채색 영역 | x, y 모두 2..29 (외곽선은 자동으로 1..30에 붙음, 0과 31은 항상 투명) |
| 크기 | 긴 변 22px 이상 (권장 24~28). 가는 물체는 대각선으로 배치 |
| 중심 | 채색 영역의 중심이 캔버스 중심에서 ±1.5px 이내 |
| 색 | `tools/pixelkit.py`의 PALETTE만. 아이콘당 램프 5개·16색 이하 |
| 외곽선 | **직접 그리지 않는다.** 빌드 시 인접 색 램프의 0단계로 자동 생성 |
| 광원 | 좌상단. 밝은 면은 왼쪽 위, 그림자는 오른쪽 아래 |

## 2. 색 지정

램프: `red orange yellow green teal blue purple pink brown tan cream gray`
단계: `0` 외곽선색 · `1` 어두움 · `2` 기본 · `3` 밝음 · `4` 하이라이트

- `"red"` (숫자 없음) → **자동 명암**: 기본색으로 채우고 좌상단 가장자리에 3, 우하단 가장자리에 1을 띠로 넣는다. 둥글고 유기적인 덩어리에 쓴다.
- `"red3"` (숫자 있음) → 그 색 그대로. 각진 면, 무늬, 디테일에 쓴다.
- 하이라이트(4)는 아이콘당 2~6픽셀만. 안쪽 구분선이 필요하면 0단계를 쓴다.
- 흰색 계열은 `cream`, 금속·유리·김은 `gray`, 빵·반죽은 `tan`, 나무·구운 색은 `brown`.

## 3. API (`from pixelkit import ellipse, rect, poly, line`)

마스크 함수(픽셀 집합 반환, `|` `-` `&` 로 합성 가능):
`ellipse(cx, cy, rx, ry)` · `rect(x0, y0, x1, y1)` · `poly([(x, y), ...])` · `line(x0, y0, x1, y1, width=1)`

캔버스 메서드:
- `c.fill(mask, color, light=None, shadow=None)` — 마스크 칠하기. `shadow=0`/`light=0`으로 자동 명암 띠 끄기, 숫자로 두께 지정
- `c.ellipse(...)`, `c.rect(...)`, `c.poly(...)`, `c.line(...)`, `c.px(x, y, color)` — 도형 하나를 바로 칠하는 단축형
- `c.grid(x, y, rows, legend)` — 문자 그림으로 작은 디테일 찍기 (`.`은 건너뜀)
- `c.recolor(mask, color)` — 이미 칠한 곳 중 mask 안쪽만 색 변경 (무늬·그림자)
- `c.erase(mask)` — 지우기

좌표는 왼쪽 위가 (0,0). 짝수 폭의 타원은 중심을 `15.5`처럼 .5로 둔다.
나중에 칠한 것이 위에 덮인다 → 뒤에 있는 것부터 그린다.

## 4. 그리는 순서

1. **실루엣 먼저.** 큰 덩어리 1~3개로 형태를 잡는다. 겹치는 덩어리는 마스크를 합쳐(`|`) 한 번에 `fill` 해야 명암이 하나로 이어진다.
2. **부속물** (꼭지, 잎, 뼈, 손잡이)을 다른 램프로 얹는다.
3. **디테일** 을 `grid`/`px`로 최소한만. 32px에서는 1픽셀이 크다 — 무늬는 3~6개면 충분.
4. **하이라이트** 2~6픽셀.
5. 빌드해서 **미리보기를 직접 눈으로 확인** 하고 고친다.

## 5. 작업 루프 (아이콘마다)

```
python tools/build.py <category>/<id>     # 검사 + build/preview/<category>/<id>.png 생성
```

1. 미리보기 PNG를 **이미지로 열어 본다** (왼쪽: 10배 확대, 오른쪽: 실제 크기 ×2, ×1 / 어두운·밝은 배경).
2. 자가 점검 — 하나라도 아니면 고치고 다시 빌드:
   - ×1 크기(오른쪽 아래)에서 **무엇인지 1초 안에 알아볼 수 있는가?**
   - 실루엣만으로 구분되는가? (덩어리가 뭉개지거나 다른 사물처럼 보이지 않는가)
   - 광원이 좌상단으로 일관되는가? 띠 모양 명암이 어색하게 끊기지 않는가?
   - 어두운 배경과 밝은 배경 모두에서 읽히는가?
   - 기준 아이콘(apple, cheese)과 나란히 놓았을 때 크기·채도·디테일 밀도가 비슷한가?
3. `ERROR`가 0이어야 한다. `warn`은 의도한 것이면 허용.
4. 아이콘당 최소 2회, 최대 6회 반복. 6회 안에 만족스럽지 않으면 가장 나은 상태로 두고 보고에 적는다.

# 스타일 가이드 / 작업 지침서

아이콘 1개 = `icons/<category>/<id>.py` 파일 1개. `def draw(c):` 하나만 정의한다.
모든 작업자(사람·AI)는 이 문서와 기준 아이콘 2개만 보고 같은 품질을 내야 한다.

- 기준 아이콘(둥근 물체): `icons/food/apple.py` — `blob` 유기적 외형 + 자동 입체 명암
- 기준 아이콘(각진 물체): `icons/food/cheese.py` — 면 단위 고정색

## 1. 고정 규칙 (도구가 강제)

| 항목 | 규칙 |
|---|---|
| 캔버스 | 32×32, 투명 배경, 알파는 0 또는 255만 |
| 채색 영역 | x, y 모두 2..29 (외곽선은 자동으로 1..30에 붙음, 0과 31은 항상 투명) |
| 크기 | 긴 변 22px 이상 (권장 24~28). 가는 물체는 대각선으로 배치 |
| 중심 | 채색 영역의 중심이 캔버스 중심에서 ±1.5px 이내 |
| 색 | `tools/pixelkit.py`의 PALETTE만. 아이콘당 램프 5개·16색 이하 |
| 외곽선 | **직접 그리지 않는다.** 빌드 시 인접 색 램프의 0단계로 자동 생성 |
| 광원 | 좌상단. 밝은 면은 왼쪽 위, 그림자는 오른쪽 아래 |

## 2. 색 지정

램프: `red orange yellow green teal blue purple pink brown tan cream gray`
단계: `0` 외곽선색 · `1` 어두움 · `2` 기본 · `3` 밝음 · `4` 하이라이트

- `"red"` (숫자 없음) → **자동 입체 명암**: 덩어리를 부풀어 오른 입체로 보고 좌상단 광원으로 1~4단계를 계산한다 (하이라이트 포함). 기본은 덩어리 전체가 공처럼 둥글고, `round=2~4`를 주면 납작한 물체의 모서리만 둥글어진다.
- `"red3"` (숫자 있음) → 그 색 그대로. 각진 면, 무늬, 디테일에 쓴다.
- 하이라이트(4)는 아이콘당 2~6픽셀만. 안쪽 구분선이 필요하면 0단계를 쓴다.
- 흰색 계열은 `cream`, 금속·유리·김은 `gray`, 빵·반죽은 `tan`, 나무·구운 색은 `brown`.

## 3. API (`from pixelkit import ellipse, rect, poly, line`)

마스크 함수(픽셀 집합 반환, `|` `-` `&` 로 합성 가능):
`ellipse(cx, cy, rx, ry)` · `rect(x0, y0, x1, y1)` · `poly([(x, y), ...])` · `line(x0, y0, x1, y1, width=1)`
`blob([(x, y), ...])` — 조절점을 부드럽게 잇는 닫힌 곡선. **자연물(과일·고기·빵·잎)의 외형은 타원 합성 대신 이것으로** 잡는다. 조절점 6~12개, 소수 좌표 가능. 좌우를 살짝 비대칭으로 두면 덜 인위적이다.
`despike(mask)` — 가시 픽셀 제거 (ellipse/blob/자동 명암 fill에는 자동 적용됨).
`rotate(mask, deg, cx=15.5, cy=15.5)` — 마스크를 시계 방향으로 회전. 병·생선·당근처럼 긴 물체는 똑바로 만든 뒤 ±45도 돌린다 (회전 수식을 직접 쓰지 않는다).

캔버스 메서드:
- `c.fill(mask, color, round=None)` — 마스크 칠하기 (`light=`/`shadow=`는 구버전 띠 명암, 새로 쓰지 않는다)
- `c.blob(points, color, round=None)` — blob 외형을 바로 칠하기
- `c.cast(mask)` — 위에 얹을 부품이 아래 물체에 드리우는 그림자(우하단 2px, 한 단계 어둡게). 부품을 칠하기 **직전**에 호출한다. 겹친 부품 사이의 깊이감을 만든다
- `c.ellipse(...)`, `c.rect(...)`, `c.poly(...)`, `c.line(...)`, `c.px(x, y, color)` — 도형 하나를 바로 칠하는 단축형
- `c.grid(x, y, rows, legend)` — 문자 그림으로 작은 디테일 찍기 (`.`은 건너뜀)
- `c.recolor(mask, color)` — 이미 칠한 곳 중 mask 안쪽만 색 변경 (무늬·그림자)
- `c.erase(mask)` — 지우기

좌표는 왼쪽 위가 (0,0). 짝수 폭의 타원은 중심을 `15.5`처럼 .5로 둔다.
나중에 칠한 것이 위에 덮인다 → 뒤에 있는 것부터 그린다.

### 입체감 규칙

- **외형**: 완벽한 원·타원·직선 대칭은 인위적으로 보인다. 자연물은 `blob`으로 잡고, 무게가 아래로 처지게(아래가 넓게/둥글게) 한다.
- **가시 금지**: 평평하거나 완만한 변 위에 1px만 튀어나오면 lint ERROR. 뾰족한 끝은 1→3→5px로 좁혀 만든다.
- **덩어리마다 입체 명암**: 큰 덩어리는 램프 이름으로 칠해 자동 입체 명암을 받는다. 고정색 한 장으로 넓은 면을 칠하지 않는다 (각진 물체의 면 구분은 예외 — cheese 참고).
- **겹침에는 그림자**: 부품을 얹기 전에 `c.cast(부품마스크)`. 포도알·체리처럼 겹친 알갱이는 뒤→앞 순서로 `cast` 후 `fill`.
- **가늘거나 작은 부품** (뼈, 줄기, 손잡이; 두께 3px 이하): 고정 단계색으로 칠하고 우하단 1줄만 한 단계 어둡게.
- **구멍** (도넛): 구멍 없이 칠한 뒤 `erase`로 뚫고, 구멍 좌상단 안쪽 테두리를 1단계로.
- **납작한 것** (접시, 쿠키, 달걀 흰자, 병·잔의 몸통): `round=2~3`.
- **회전 주의**: `rotate`는 큰 덩어리(병 몸통, 뼈)에만. 눈·지느러미·라벨 선 같은 1~2px 디테일은 회전하면 뭉개지므로 회전 후에 따로 그리거나, 처음부터 `blob` 조절점을 대각선으로 놓는다. 회전 결과는 `despike(rotate(...))`로 감싼다.
- **흰 도자기·밥·달걀 흰자**: `cream3` 바탕 + `cream2` 그림자. `cream1`은 넓게 쓰지 않는다 (때 탄 것처럼 보임).
- **김·연기**: 외곽선이 붙어 두꺼워진다 → 짧게 2가닥 이하, `gray3`/`cream3`만.

## 4. 그리는 순서

1. **실루엣 먼저.** 큰 덩어리 1~3개로 형태를 잡는다 (자연물은 `blob`). 한 물체를 이루는 덩어리는 마스크를 합쳐(`|`) 한 번에 `fill` 해야 명암이 하나로 이어진다.
2. **부속물** (꼭지, 잎, 뼈, 손잡이)을 다른 램프로 얹는다.
3. **디테일** 을 `grid`/`px`로 최소한만. 32px에서는 1픽셀이 크다 — 무늬는 3~6개면 충분.
4. **하이라이트** 는 자동으로 들어간다. 부족할 때만 4단계 1~3픽셀 추가.
5. 빌드해서 **미리보기를 직접 눈으로 확인** 하고 고친다.

## 5. 작업 루프 (아이콘마다)

```
python tools/build.py <category>/<id>     # 검사 + build/preview/<category>/<id>.png 생성
```

0. **빌드 출력을 먼저 읽는다.** lint가 실패해도 미리보기는 만들어진다.
1. 미리보기 PNG를 **이미지로 열어 본다** (왼쪽: 10배 확대, 오른쪽: 실제 크기 ×2, ×1 / 어두운·밝은 배경).
2. 자가 점검 — 하나라도 아니면 고치고 다시 빌드:
   - ×1 크기(오른쪽 아래)에서 **무엇인지 1초 안에 알아볼 수 있는가?**
   - 실루엣만으로 구분되는가? (덩어리가 뭉개지거나 다른 사물처럼 보이지 않는가)
   - 광원이 좌상단으로 일관되는가? **평면 스티커가 아니라 부피가 있는 물체로 보이는가?**
   - 외곽이 기계적인 원/직선이 아니라 자연스러운가? 튀어나온 가시 픽셀이 없는가?
   - 어두운 배경과 밝은 배경 모두에서 읽히는가?
   - 기준 아이콘(apple, cheese)과 나란히 놓았을 때 크기·채도·디테일 밀도가 비슷한가?
3. `ERROR`가 0이어야 한다. `warn`은 의도한 것이면 허용.
4. 아이콘당 최소 2회, 최대 6회 반복. 6회 안에 만족스럽지 않으면 가장 나은 상태로 두고 보고에 적는다.
